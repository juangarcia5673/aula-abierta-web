# Evidencias de comprobación

Las capturas fueron producidas con Chromium/Playwright a partir de los archivos entregados integrados en una página de prueba equivalente (el entorno de ejecución bloquea la carga de direcciones locales). El CSS y el JavaScript probados son los mismos que los del proyecto.

- `captura_movil_390.png`: página completa con viewport de 390 px.
- `captura_tablet_768.png`: página completa con viewport de 768 px.
- `captura_escritorio_1440.png`: página completa con viewport de 1440 px.
- `vista_movil_390.png`, `vista_tablet_768.png`, `vista_escritorio_1440.png`: primera vista de cada ancho.
- `vista_movil_320.png`: vista adicional de un viewport estrecho.
- `resultados_pruebas.json`: resultados de las pruebas funcionales y adaptables.

Se comprobaron enlaces de navegación internos, identificadores únicos, una sola etiqueta h1, alternativas textuales de imágenes y etiquetas de formulario asociadas. No se observó desbordamiento horizontal a 320, 390, 768 ni 1440 px. La revisión con tecnologías de asistencia reales permanece pendiente.
